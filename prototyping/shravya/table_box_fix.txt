# P3 fix: Table box covered only the figure columns (Part 9 eval.md finding 6)

Problem (10-K p32): detected Table bbox [362.04, 105.76, 603.1, 557.99] covers the figures only; the row labels
were saved again as 7 Text/Title blocks, so the export carried them twice.

Fix (src/layout.py absorb_table_rows): for a Table that routing extracted, the stored bbox is widened to the words on
its rows (detector box kept as detected_bbox), and Text/List/Title blocks centred in its rows are dropped only if
>= 80% of their words appear in BOTH the routed table and Part 2's table CSVs for the page (the tables export uses).

10-K p32 after: bbox [7.0, 105.76, 604.45, 557.99] (Docling: 5.5 to 607), 7 blocks absorbed, table text starts with
"Net sales: | Products $ 307,003 ...".

What broke on the way: the first version (absorb by position only) made 10-Q p11 and p16 worse (WER 0.707 -> 0.766,
0.751 -> 0.849): absorbed labels were in layout's routed table but not in Part 2's CSVs, which the export uses.
Requiring the words in both tables fixed it; no page is worse in the final version.
